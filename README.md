
Jekyll Single page
==================

[Live](http://marcodalalba.com)

## Why:
Got some *killer app*, some *neat project*, a cool portfolio? Make an easy single-page site to show it all off. SinglePaged uses jekyll niceties to make a ***polished, modular, and beautiful* single page site**.

-------------------------

## Setup as user homepage

- Go click **fork** on the [github project page](https://github.com/vinisdl/vinisdl.github.io)
- Rename your new repository to `**username**.github.io`. (click settings in the right column)
- Clone your repository, **cd into the project**
- Config file _confi_yml
- create your post with the format '20160711-intro'
~~~
---
layout: post
title:  "Home"
date:   2016-07-11
categories: inicio
style: intro
---
Content

~~~

**When you publish changes use `git push -u origin master`**
